Модель обрабатывает видео покадрово и ищет там людей  
По итогу мы имеет набор людей на каждом кадре

Дальше переворачиваем группировку чтобы на каждого человека был набор кадров (либо сразу пытаться выдавать такую структуру моделью)  
По такой структуре мы по факту имеем наборы интервалов обнаружения каждого человека с точностью до кадра

Дальше нужно будет вывести алгоритм для агрегации интервалов  
Задача состоит в том чтобы из покадровых меток получить метки раз в 5 минут
Объединение в подынтервалы 
Набросок алгоритма (надо будет уточнять и детализировать позже)  
Можно собрать наборы кадров в набор структур { начало_интервала, конец_интервала }  
То есть из условного [ 65:45:34.13, 65:45:34.14, 65:45:34.15, 65:45:34.16, 65:45:34.17 ] мы получаем { начало_интервала: 65:45:34.13, конец_интервала: 65:45:34.17 }

Дальше надо будет определить какое максимальное расстояние между интервалами может быть чтобы считать это непрерывным присутствием  
Например если максимальное расстояние равно 10 секундам то есть 00:00:10.00   
То тогда интервалы { начало_интервала: 00:20:34.00, конец_интервала: 00:20:34.42 } и { начало_интервала: 00:20:43.15, конец_интервала: 00:20:44.00 } мы будем считать как один { начало_интервала: 00:20:34.00, конец_интервала: 00:20:44.00 } потому что разница между концом первого и началом второго меньше 10 секунд.  
10 секунд лишь пример конечное значение может быть любым (это надо обсудить)

Таким образом мы получим относительно большие интервалы

Теперь можно приступать к созданию набора меток  
Здесь предлагаю поступить так  
Первой меткой будет всегда самая первая метка фиксации то есть начало самого первого интервала для человека  
Дальше мы прибавляем к этой метке 5 минут (искомое время) и начинаем поиск  
Тут два варианта  
1. Если время искомое время попадает в пределы одного из интервалов, то сохраняем метку и ищем следующую  
2. Если время искомое время не попадает в пределы какого либо из интервалов, то мы ищем интервал начало которого ближе всего с искомому времени, но позже его. Начало такого интервала и является следующей меткой.  
Если же более поздних интервалов нет то прерываем поиск
