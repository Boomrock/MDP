### Псевдокод алгоритма

```
    Инициализировать структуру для хранения временных меток по каждому объекту
	входных_данных := [{Человек; Время кадра}, {Человек; Время кадра}]
    // Шаг 1: Группировка данных
    Для каждой записи в входных_данных:
        Извлечь объект и соответствующее время
        Добавить время в структуру для данного объекта
	человек_кадры:= [{Человек: [Время кадра, время кадра]},{Человек: [Время кадра, время кадра]}]

    // Шаг 2: Сортировка временных меток
    Для каждого объекта в человек_кадры:
        Отсортировать временные метки
    // Шаг 3: Определение меток времени
	Инициализировать список_для_меток_по_объектов
    max_distance := 5 минут;
    Для каждого объекта в человек_кадры:
		Добавляем в список_для_меток_по_объектов время первого кадра
        Установить индекс для прохода по времени кадров, равный 1. (Для второго кадра)
        Пока индекс меньше длины массива временных меток:
            Получить текущий кадр 
            Если разница между прошлым временм и текущем временем кадра > max_distance:
	            добавляем текущую метку в список_для_меток_по_объектов
	        Иначе:
	            Если разница между последней меткой в список_для_меток_по_объектов и текущей времени кадра > чем max_distance: 
		            Добавляем в список_для_меток_по_объектов время последней меткой в списоке_для_меток_по_объектов + max_distance
    Вернуть структуру с метками времени
```
